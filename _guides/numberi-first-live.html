Number_i（ナンバーアイ）のライブに、はじめて行く人のためのページです。入場のしかた、本人確認、席の種類、無線で光るペンライトの座席登録、コール、定番曲、グッズ、帰りの宿まで、公式の案内で確かめたことだけをまとめました（2026年11月25日時点）。

全会場の日程・時刻・セトリは：Number_i LIVE TOUR No.III 2026-2027まとめ（日程・時刻・セトリ）

🎫 まず押さえる3つ

Number_iのライブは、TOBE IDと、スマホで見せる入場の二次元コードが基本です。ファンクラブのチケットは、来場する全員（同行者も）がTOBE ID（無料）を取ってMOALAのアカウントと連携しておく必要があります。

🎫 チケットの受付（先行の種類・期間・対象）は：Number_i LIVE TOUR No.III まとめ「チケットの受付」

  1. 全員がTOBE IDを用意来場する全員がTOBE ID（無料）を取り、MOALAのアカウントと連携。ファンクラブのチケットはMOALA Ticket（ブラウザで表示。MOALA Pocketアプリは使わない）
  2. 本人確認書類を持っていく入口や座席で本人確認があることも。TOBE IDの登録と同じ名前の公的な書類（運転免許証・マイナンバーカード・パスポートなど顔写真付きなら1点）。コピー・期限切れは使えない
  3. ペンライトは座席を登録ツアーの公式ペンライトは無線で色が変わる演出つき。専用アプリで公演ごとに座席を登録しておく。公式グッズでない光るものは持ち込めない
VIP GOLD席の入場は？

VIP GOLD席だけは顔認証で入場します（代表者・同行者とも事前に顔写真を登録。登録した写真は1年間変えられない）。入口で顔と二次元コードを端末に見せるので、帽子・サングラス・マスクは外します。顔写真付きの本人確認書類も全員が持っていきます（顔写真付きのものがない場合に顔写真なしの書類2点で入れるのは高校生まで）。ほかの席は顔写真の登録はありません。

🕓 当日の流れ

  1. 前日まで入場とペンライトの準備TOBE IDとMOALAの連携・同行者の登録を確かめる。座席番号が出たら入場の二次元コードをスクリーンショットしておくと安心（公式の案内）。ペンライトの座席登録は公演ごとに
  2. 16:30開場係員に二次元コードを見せて入場（VIP GOLD席は顔認証）。本人確認があることも。会場にはペンライトのサポートブース
  3. 18:30開演無許可の撮影・録音は禁止。公式でない光るものは使えない。一度出ると再入場できない
  4. 終演後帰る・泊まる規制退場になることがある。終演の時刻は未発表。大阪・東京は平日の夜なので、遠くから行く人は会場の近くの宿も早めに

🔦 ペンライト（4色）

ツアーの公式ペンライト「[No.Ⅲ]オリジナルペンライト」は、無線で色が変わる演出に対応しています。事前に専用アプリ（無料）でその公演の座席を登録しておきます。登録は公演ごとに必要で、公演中はアプリはいりません。1台のスマホで何本でも登録でき、ほかの席で登録したペンライトを使うと演出がずれます。電池が減ると色が赤っぽくなるので、公演ごとの電池交換が案内されています。色は次の4つで、演出中は自動で切り替わります。

  1. WHITE
  2. PURPLE
  3. BLUE
  4. RED
